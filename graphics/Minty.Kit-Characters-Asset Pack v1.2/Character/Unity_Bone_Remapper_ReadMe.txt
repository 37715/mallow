In Unity

If you are using the Character_Base and wish to attach the separate items like clothing and accessories which themselves have a skinned animation, you would need to remap the Clothing item's bones to use the Character_Base bones.

This can be done by manually relinking bone by bone.
However, here is a helpful Bone Remapper script developed by youtuber Studio Jaw that you can find explained in the link and download the script:

https://youtu.be/sH6jCMLfI6Q?list=PLQrTp8AxswNCotk4Vd5fJwT7-JnkZj69M

I have used it personally and it works like magic!


You would need this when you're trying to merge items from future accessory additions, clothing or character updates.
